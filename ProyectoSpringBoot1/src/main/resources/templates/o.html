Principio de abierto cerrado

El principio de abierto cerrado establece que las entidades de software deben estar abiertas a la extensión, pero cerradas a la modificación. Esto significa que debe ser posible agregar nuevos comportamientos sin cambiar el código existente que ya funciona.

Por ejemplo, un sistema de pagos puede utilizar una interfaz común para procesar pagos. Si se necesita agregar un nuevo método de pago, se crea otra clase que implemente esa interfaz, sin modificar las clases de los métodos anteriores ni el código que utiliza la interfaz.
